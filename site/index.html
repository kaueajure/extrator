WebRioPreto Extrator
Abrir painel WebRP

Prospecte no Google Maps. Importe no WebRP.

Aplicativo desktop para buscar empresas por região, filtrar leads com score e enviar direto ao funil comercial do painel Web Rio Preto.

Download

Escolha o sistema do seu computador. Não precisa instalar Python.

Windows (.zip) Linux (.tar.gz)

Versão publicada via GitHub Releases. Requer login de desenvolvedor no WebRP.

Windows

  1. Extraia o arquivo .zip em uma pasta (ex.: C:\WebRP-Extrator).
  2. Copie .env.example para .env e preencha URL e banco.
  3. Abra WebRP-Extrator.bat (não clique só no .exe).
Use sempre o arquivo .bat — ele aponta o navegador embutido na pasta.

Linux

  1. Extraia: tar -xzf WebRP-Extrator-linux.tar.gz
  2. Configure o .env com as mesmas credenciais do painel.
  3. Execute: ./webrp-extrator.sh
Ubuntu/Debian: se faltar biblioteca Qt — sudo apt install libxcb-cursor0 libxkbcommon-x11-0 libegl1

Configuração do .env

  • WEBRP_URL — URL do painel (ex.: https://webriopreto.com)
  • DB_HOST, DB_USER, DB_PASSWORD, DB_NAME — mesmo MySQL do WebRP (cruzamento e importação)
  • GEMINI_API_KEY — opcional, melhora sugestões de busca
