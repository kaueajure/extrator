WebRP Extrator — Linux
======================

1. Baixe WebRP-Extrator-Setup.run
2. Torne executável e rode:
     chmod +x WebRP-Extrator-Setup.run
     ./WebRP-Extrator-Setup.run
3. Abra "WebRP Extrator" no menu de aplicativos, ou no terminal:
     webrp-extrator

Não é necessário configurar .env. O app já aponta para https://webriopreto.com.

Se faltar biblioteca Qt (Ubuntu/Debian):
  sudo apt install libxcb-cursor0 libxkbcommon-x11-0 libegl1
